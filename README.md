# まんまるお菓子工房

このゲームは、スマホのブラウザで遊べるシンプルなお菓子作りクリッカーです。
画面中央の大きな丸い焼き菓子をタップして、たくさんのお菓子を作り、工房のアップグレードを買って成長させます。

## ゲームの概要

- 画面中央の丸い焼き菓子をタップすると、お菓子が増えます。
- ためたお菓子で工房のアップグレードを購入します。
- 購入したものによって、1秒ごとに自動でお菓子が増えます。
- オフライン中にも、一定量だけお菓子を受け取れます。
- 実績を達成すると、工房の成長を楽しめます。

## 各ファイルの役割

- index.html
  - 画面の構成を決めます。
  - タイトル、数値表示、丸いお菓子ボタン、アップグレード一覧、実績一覧を配置します。
- style.css
  - お菓子工房の温かい雰囲気を作ります。
  - スマホ向けの大きなボタン、カード、色をまとめて調整します。
- game.js
  - タップ量、アップグレード、保存、実績、オフライン進行の計算を担当します。
  - バランスの数値は CONFIG の中にまとめています。
- README.md
  - ゲームの使い方や公開方法をまとめた説明書です。
- AGENTS.md
  - 今後の修正時に守るルールをまとめたメモです。

## スマホでも開発しやすい環境のおすすめ方法

このゲームは HTML と JavaScript だけなので、スマホからでも開発しやすい構成です。
一番おすすめは、次の流れです。

1. GitHub でこのリポジトリを作成します。
2. スマホで「GitHub」または「VS Code」を使って、同じリポジトリを開きます。
3. index.html、style.css、game.js をスマホから直接編集します。
4. 編集後に、ブラウザで index.html を開いて動作確認します。
5. 変更を GitHub に保存して、GitHub Pages に反映させます。

この方法の良い点は、外部ライブラリが不要で、ファイルが少ないので手軽に触れることです。
スマホからの編集では、ファイルを1つずつ見ながら調整しやすく、初心者向けの開発に向いています。

## PCでゲームを開く方法

1. フォルダを開きます。
2. index.html をダブルクリックします。
3. ブラウザが開いてゲームが起動します。

このゲームはブラウザだけで動くので、インストールは不要です。

## スマホで確認する方法

1. 同じフォルダをスマホに送るか、GitHub 上で公開します。
2. スマホのブラウザで index.html を開きます。
3. ローカルファイルでは挙動が制限されることがあるので、GitHub Pages などを使うのが安心です。

## GitHub Pagesで公開する手順

1. GitHub でこのリポジトリを作成します。
2. すべてのファイルをアップロードします。
3. GitHub の Settings → Pages を開きます。
4. Source を「Deploy from a branch」にして、main ブランチを指定します。
5. 保存するとURLが発行されます。
6. そのURLをブラウザで開けば遊べます。

ビルド処理が不要なので、GitHub Pages にそのまま載せやすいです。

## ゲームバランスの数値を変更する場所

ゲームの数値は、game.js の最初にある CONFIG にまとめています。

- initialClickPower
  - 1回のタップで増えるお菓子数です。
- shop
  - 各アップグレードの価格や効果です。
- offlineCapSeconds
  - オフラインで受け取れる最大時間です。
- offlineMultiplier
  - オフラインで受け取る倍率です。

初心者の方は、この設定だけを変えれば、ゲームの進み方を調整しやすいです。

## 色や文章を変更する場所

- 色の変更: style.css
- タイトルや説明文の変更: index.html
- ゲーム中の表示文: game.js

特に style.css は、見た目の調整が最も簡単です。

## セーブデータをリセットする方法

画面下の「セーブデータをリセット」を押します。
確認ダイアログが出るので、「はい」を押すと保存データが削除されます。

保存データはブラウザの localStorage に入っています。
このデータはブラウザ設定からも削除できますが、通常は画面のボタンを使うと簡単です。

## 古い保存データへの対応

過去のゲームデータが残っている場合、ゲームは自動で新しい形式へ変換しようとします。
変換できない古いデータがあれば、初期状態から始める案内を出します。

## 不具合が起きた場合の基本的な確認方法

1. ブラウザの更新ボタンを押して再読み込みします。
2. 開発者ツールの Console を開いて、エラーが出ていないか確認します。
3. game.js の initialize() が動いているか確認します。
4. セーブができていないときは、ブラウザの保存が有効か確認します。

初心者向けに言うと、「JavaScriptにエラーが出ていないかを見る」ことが一番大事です。

## 用語の簡単な説明

- localStorage
  - ブラウザ内にデータを保存する仕組みです。
- クリッカーゲーム
  - ボタンや対象を何度も押して、数を増やしていくゲームです。
- オフライン進行
  - ゲームを閉じていた間にも、少しだけ自動で進む仕組みです。

このゲームは、ボタンを押すだけで遊べるので、最初は少しずつ慣れていけば大丈夫です。
